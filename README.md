# 正缘画像 · Letters to Love

中文、移动端优先的关系偏好测试网站。React + TypeScript + Vite 前端，Express + Node 内置 SQLite 后端；不依赖 Supabase 或外部账号即可在本机运行。信笺、星轨与三类结果插画均为内置 SVG，海报为浏览器生成的 1080 × 1440 PNG。

## 在新机器启动

安装 Node.js **24 LTS**（使用内置 `node:sqlite`）。推荐 pnpm 11，也可使用 npm：

```sh
npm install
npm run admin:init
npm run dev
```

使用 pnpm 时，仓库已提供锁文件及 esbuild 构建白名单：

```sh
pnpm install --frozen-lockfile
pnpm admin:init
pnpm dev
```

第一次启动服务会运行数据库迁移，并导入规范附录的 18 题、72 个选项及全部原文结果。初始化为幂等操作，不覆盖已有版本。初始管理员只允许在本机命令行创建，凭据写入被 Git 忽略的 `first-login.txt`。后台入口为 `/admin/login`。初次登录后可在“账号权限”编辑账号与密码。

## 配置与部署

复制 `.env.example` 为 `.env`。本机无需修改；上线必须设置实际公开域名与运营联系方式：

```dotenv
PORT=4173
HOST=127.0.0.1
PUBLIC_ORIGIN=https://your-domain.example
COOKIE_SECURE=true
CONTACT_EMAIL=your-contact@example.com
```

执行 `npm run build`，使用 `npm start` 启动生产模式。用反向代理终止 HTTPS，并代理到本机 4173 端口。SQLite 的 `data/` 应放在持久卷并限制系统文件访问；备份使用 SQLite 一致性备份方案。多实例或大量并发部署应迁移到 PostgreSQL 并使用共享限流存储。

**这不是纯静态站点。** GitHub 仓库存放源码；GitHub Pages 无法运行 SQLite、服务端计分与管理员登录，需要支持 Node.js 的服务器。海报二维码在本机默认指向 `http://localhost:4173/`；只有设置并部署真实 `PUBLIC_ORIGIN` 后，其他人的手机才能访问。

原始会话、答案、结果及事件在会话开始后 30 天清理（启动时及每小时），浏览器进度同期限；管理员会话为 8 小时，操作日志保留 180 天。删除接口会级联删除当前匿名设备所属记录，旧链接随之失效。统计以首次访问事件时间组成筛选队列，不是自然日新增访问次数，口径在后台明确展示。

## 实现范围说明

这是可运行的本地全栈实现，统计来自真实数据库。当前使用 SQLite 服务层所有者约束与角色授权，而非 Supabase RLS；数据库文件只由服务进程打开。单节点部署是当前适用范围。

首页、结果文案和结果封面可在后台维护。品牌矢量标识、星轨插画及海报结构是代码模板，分别在 `src/Art.tsx`、`src/share.tsx`、`src/styles.css` 维护，尚未提供可视化拖拽设计器。图片上传校验 MIME、魔数与大小；生产环境可再接入独立对象存储及图片转码服务。
